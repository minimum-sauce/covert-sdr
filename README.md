# covert-sdr
This project implements Covert Communication on an ANTSDR 

# Custom ANTSDR firmware
The following firmware is forked and altered from the following repository: https://github.com/MicroPhase/antsdr-fw-patch

## Build firmware
start by running the following command to pull the entire submodule structure to your local machine:
```bash
git submodule update --init --recursive antsdr-fw
```
NOTE: This will take a while to pull.
Build instructions for the firmware can then be found in the `antsdr-fw/` submodule.
